# 参考
广义的系统科学还包括耗散结构论、协同学、突变论、模糊数学、物元分析、泛系方法论、系统动力学、灰色系统论、系统工程学、计算机科学、人工智能学、知识工程学、传播学等

- 耗散结构：一个远离平衡态的非线性的开放系统（不管是物理的、化学的、生物的乃至社会的、经济的系统）通过不断地与外界交换物质和能量，在系统内部某个参量的变化达到一定的阈值时，通过涨落，系统可能发生突变即非平衡相变，由原来的混沌无序状态转变为一种在时间上、空间上或功能上的有序状态。这种在远离平衡的非线性区形成的新的稳定的宏观有序结构，由于需要不断与外界交换物质或能量才能维持，因此称之为“耗散结构”（dissipative structure）。
    - 非线性
    - 远离平衡态
    - 开放系统：①与外界既无能量交换又无物质交换的孤立系统；②与外界有能量交换但无物质交换的封闭系统；③与外界既有能量交换又有物质交换的开放系统。
    - 涨落
    - 突变
- 耗散结构的改进
    - 区分结构有序化与能量有序化，用“熵变能”（或有序化能量）取代“负熵”。
    - 区分直接有序化能量与间接能量有序化能量，用“广义有序化能量作”取代“广义负熵”。
    - 区分功能有序与结构有序，用“价值率”来替代“序参量”。
    - 区分信息的功能特性与结构特性，准确把握信息的本质。信息的本质在于“消除不确定性”，由于“不确定性”实际上就是“无序性”，因此“消除不确定性”就等价于“提高有序性”或“降低无序性”，同样，信息对于对于耗散结构的作用就是提高耗散结构的功能有序性，而不是提高耗散结构的结构有序性。信息是一种特殊的价值，它并不是直接为耗散结构提供广义有序化能量，而是通过改变耗散结构对于广义有序化能量的使用效益，来服务于耗散结构。具体而言，就是提高耗散结构的价值率。信息的准确定义是：“一切能够改变事物价值率的内外因素称为信息”（参阅“价值的哲学本质”）。


# 案例
20世纪40年代美国贝尔电话公司在发展通信技术时，使用了系统工程的方法。美国研制原子弹的曼哈顿计划，是系统工程的成功实践。美国国防部设立的系统分析部，在军事决策方面运用了系统方法。  
50年代: 理论研究和教学工作全面展开，《一般系统论年鉴》《系统工程》麻省理工学院等院校还为此开设了系统工程的课程
60年代: 贝塔朗菲发表了《一般系统论——基础、发展、应用》的著作，英国军事部门的科学家研究和解决雷达系统的应用问题，提出了运筹学。
80年代以后: 非线性和复杂性系统研究
