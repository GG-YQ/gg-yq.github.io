# web
## http
- 基本结构
    - 请求参数
        - 请求行：协议版本、请求方式、路径参数（path）、查询参数（query）
        - 请求头参数（head）
        - 请求体参数（body）
    - 响应参数
        - 响应行：协议、状态码
        - 响应头
        - 响应体
- 请求类型
    |请求类型|适用场景|参数说明|
    |-|-|-|
    |get|获取数据|只能传Query参数：`url_path?query参数1&query参数2`|
    |post|非幂等：新建数据|可以传Query和Body两种形式的参数|
    |put|幂等：更新数据||
    |delete||||

## html
- 表单form：在点击提交铵钮时，浏览器自动收集参数，并打包一个http请求到服务器，完成表单提交。在这一过程中，浏览器会根据method的不同，将参数编码后，放在urI中(get)，或者放在请求的data中(post)，然后发送到服务器。如果没有`<form></form>`，post方式的提交要使用ajax手工完成。get方式的提交需要自己拼接url。
    - 优点：支持发送大量数据和敏感信息；安全性较高，表单数据不会暴露在URL中。
    - 缺点：不适合用于书签或浏览器历史记录中的保存和分享；对服务器资源有更高的消耗，特别是处理大文件上传时。

- web worker: 当在 HTML 页面中执行脚本时，页面的状态是不可响应的，直到脚本已完成。而web worker运行在后台的 JavaScript，独立于其他脚本，不会影响页面的性能。您可以继续做任何愿意做的事情：点击、选取内容等等，而此时 web worker 在后台运行。

- 事件: 可以使用HTML事件触发浏览器中的行为。窗口、表单、鼠标、键盘、多媒体等。
